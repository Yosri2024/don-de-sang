# US-07 — Protéger mes données

**En tant que donneur**, **je veux** que mes données soient protégées, **afin de** préserver ma confidentialité.

| Champ | Valeur |
|---|---|
| ID | US-07 |
| Source | « Les données doivent être protégées » |
| Exigence liée | REQ-NF-01 |
| Priorité | À valider avec le client |
| Statut | À préciser |

## Critères d'acceptation provisoires

- [ ] Les données à protéger sont identifiées avec le client. `[point ouvert]`
- [ ] Les droits d'accès par rôle sont définis avec le client. `[point ouvert]`
- [ ] Les menaces et les règles applicables sont précisées. `[point ouvert]`
- [ ] La durée de conservation et le moyen de vérifier la protection sont définis. `[point ouvert]`

## Points ouverts
