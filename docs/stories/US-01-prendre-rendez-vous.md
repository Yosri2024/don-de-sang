# US-01 — Prendre rendez-vous pour un don

**En tant que donneur**, **je veux** prendre rendez-vous pour un don, **afin de** donner mon sang à un moment précis.

| Champ | Valeur |
|---|---|
| ID | US-01 |
| Source | « Les donneurs doivent pouvoir prendre rendez-vous pour un don » |
| Exigence liée | REQ-F-01 |
| Priorité | À valider avec le client |
| Statut | À préciser |

## Critères d'acceptation provisoires

- [ ] Le donneur peut demander un rendez-vous pour un don depuis l'application.
- [ ] Le système enregistre le rendez-vous demandé et l'associe au donneur. `[à valider]`

## Points ouverts

- Q-38 : comment le donneur s'identifie-t-il ?
- Q-40 : annulation ou modification d'un rendez-vous ?
- Q-39 : comment un nouveau donneur est-il enregistré ?
- Q-44 : sur quels appareils ?
- Q-24 : reprise des rendez-vous du cahier ?
