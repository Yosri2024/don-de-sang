# Centre de don de sang — Éligibilité des donneurs

Projet **Sujet 17** : application pour un centre de transfusion sanguine permettant de gérer les rendez-vous, vérifier l'éligibilité des donneurs, suivre les collectes et alerter les donneurs d'un groupe sanguin manquant.
